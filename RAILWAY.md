# Деплой на Railway

Бот — воркер (long polling), поэтому на Railway это обычный сервис **без домена** и без HTTP-порта.

## 1. Создать проект

1. Откройте [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
2. Выберите репозиторий `trapdrug/playerok-bot`.
3. Railway сам соберёт образ из `Dockerfile` (образ уже содержит нужный Chromium).

> Публичный репозиторий с Dockerfile собирается без ключей. Railway предложит
> «Deploy without a domain» — согласитесь, домен не нужен.

## 2. Переменные окружения

В разделе **Variables** добавьте:

| Переменная | Значение | Обязательно |
|------------|----------|--------------|
| `BOT_TOKEN` | новый токен от @BotFather | да |
| `ADMIN_LOGIN` | `gladmin` | нет (по умолчанию) |
| `ADMIN_INITIAL_PASSWORD` | любой пароль (бот попросит сменить при первом входе) | да |
| `FERNET_KEY` | сгенерировать: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` | да |
| `DRY_RUN` | `true` на старте, потом LIVE переключается в боте | нет (по умолчанию `true`) |
| `TIMEZONE` | `Europe/Moscow` | нет |
| `POLL_INTERVAL_SECONDS` | `60` | нет |
| `PLAYEROK_USERNAME` | ваш ник на Playerok (необязательно) | нет |

`DATA_DIR=/data` и `DATABASE_URL=sqlite+aiosqlite:////data/playerok.db` уже заданы в
`Dockerfile`, их менять не нужно.

**Важно:** используйте **новый** токен бота и **новый** `FERNET_KEY` — старые значения
из локального `.env` не выкладывайте, а локальный `.env` в репозиторий не попадает.

## 3. Volume для базы данных

SQLite-файл лежит в `/data`. На Railway файловая система контейнера эфемерна —
после каждого деплоя база пропадёт (останутся cookies, аккаунты, настройки, история).

1. В сервисе → **Volumes** → **Add Volume**.
2. Mount path: `/data`.
3. Тип: Railway Volume (10 ГБ достаточно).

Без volume бот будет стартовать с нуля: заново создастся администратор из переменных
окружения, и куки придётся загружать в Telegram заново.

## 4. Загрузить cookies Playerok

1. Найдите бота в Telegram, отправьте `/login gladmin <пароль>` (в личном чате).
2. При первом входе бот попросит сменить пароль (минимум 8 символов).
3. Отправьте боту JSON-файл с cookies Playerok — бот удалит сообщение, зашифрует
   файл (Fernet) и сохранит в базе. Дальше обновляйте файл этим же способом.

## 5. Проверка

- Логи сервиса: вкладка **Logs** — должны идти строки цикла и `audit action=...`.
- В Telegram: `/status` — сессия, лимиты, число товаров в продаже.
- Переключение в LIVE: `/dryrun off` (подтверждение в чате) — только главный админ.

## 6. Обновление селекторов

Файл `selectors.yaml` лежит в репозитории. Чтобы поменять селекторы (например, добавить
триггер `boost.skip_titles`), отредактируйте его в GitHub и задеплойте новую версию —
Railway пересоберёт образ. Файл также можно подключить как отдельный том и менять
без пересборки: mount path `/app/selectors.yaml`.

## 7. Локальная проверка без Railway

```bash
docker compose up -d --build
```
