# Инструкция по экспорту cookies для Playerok Bot

Бот принимает JSON-файл с cookies через команду `/cookies` (только главный администратор).
Сообщение с файлом удаляется сразу, cookies шифруются через Fernet и сохраняются в БД.

## Быстрый способ: скрипт экспорта (рекомендуется)

Скрипт открывает настоящий браузер с постоянным профилем, вы входите в
аккаунт руками, после чего cookies сохраняются автоматически.

```bash
# один раз установите Chromium
python -m playwright install chromium

# запустите экспорт в авто-режиме
python scripts/export_cookies.py --auto --timeout 900
```

Что произойдёт:
1. Откроется окно Chromium на `https://playerok.com/profile`.
2. Вы входите в аккаунт продавца.
3. Открываете свой профиль (`https://playerok.com/profile` или аватар →
   профиль).
4. Скрипт распознаёт авторизованную страницу и сохраняет `cookies.json`
   в корне проекта. Нажимать Enter не нужно.

Без `--auto` скрипт ждёт Enter в терминале:

```bash
python scripts/export_cookies.py
```

Проверить готовый файл можно отдельно:

```bash
python scripts/check_cookies.py
```

Скрипт откроет `/profile` с этими cookies и покажет, авторизована ли сессия.

Дальше отправьте `cookies.json` боту в Telegram. Файл содержит действующую
сессию — не пересылайте его никому и не коммитьте в git. Постоянный профиль
браузера (`data/export-profile/`) тоже содержит сессию и добавлен в
`.gitignore`.

## Поддерживаемые форматы

1. **JSON-массив cookie-объектов** (рекомендуется, как в `cookies.example.json`)
2. **Объект с полем `cookies`**: `{ "cookies": [...] }`
3. **Простой объект** `{"имя": "значение", ...}` — каждое значение становится cookie.

## Как экспортировать cookies из браузера

### Chrome / Edge / Brave / Яндекс.Браузер

1. Откройте https://playerok.com и войдите в аккаунт продавца.
2. Нажмите F12 → вкладка **Application** → **Cookies** → `https://playerok.com`.
3. Установите расширение для экспорта cookies (например, "Export cookies" / "Get cookies.txt").
   * Или скопируйте вручную все поля: `name`, `value`, `domain`, `path`, `secure`, `httpOnly`, `sameSite`, `expires`.
4. Сохраните как JSON-файл.
5. В Telegram отправьте файл боту командой `/cookies`.

### Firefox

1. F12 → **Storage** → **Cookies** → `https://playerok.com`.
2. Экспортируйте через расширение (например, "cookies.txt") и конвертируйте в JSON.
3. Отправьте JSON-файл боту.

### Playwright (альтернатива)

Если у вас уже есть скрипт на Playwright, который логинится на Playerok, можете сохранить `context.cookies()` и отправить полученный JSON боту.

## Требования к файлу

- Домен cookies должен быть `playerok.com` или `.playerok.com` (бот отбрасывает посторонние домены).
- Максимальный размер файла: 1 МБ (`MAX_COOKIE_FILE_BYTES`).
- Названия полей регистронезависимы (`name` / `Name`, `value` / `Value` и т.д.).
- Поле `expires` — Unix timestamp (число). Можно опустить для сессионных cookies.

## Что делает бот после загрузки

1. Удаляет ваше сообщение с файлом (пароли и cookies не остаются в чате).
2. Шифрует cookies через Fernet (ключ из `FERNET_KEY` в `.env`).
3. Проверяет сессию на Playerok (открывает страницу профиля).
4. Сообщает результат: сессия активна или cookies недействительны.

Если сессия истечёт, бот остановит все задачи и попросит загрузить свежий JSON с cookies.

## Безопасность

- Cookies **никогда не логируются** и не выводятся в чат.
- Ключ шифрования храните только в `.env` (`FERNET_KEY`).
- Файл `cookies.example.json` — только пример, не содержит реальных данных.
- Реальный файл с cookies не добавляйте в git (см. `.gitignore`).
